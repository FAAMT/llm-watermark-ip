# Software baselines

Generated by `python3 scripts/baseline.py`. The C loop `src/sw/wm_baseline.c` is the scalar form of
the IP's datapath (two hashes, ROM address, ROM read, add, compare per token), built with
`gcc -O3 -march=native` and run on one core of this machine (AMD RYZEN AI MAX+ 395 w/ Radeon 8060S).
The IP column is the measured RTL latency at the 100 MHz target clock (results/perf.md).
The C loop matches the golden model bit for bit on 4 SAMPLE and DETECT checks.

| job | V | C, one core | NumPy golden model | IP at 100 MHz | IP cycles |
|---|---|---|---|---|---|
| SAMPLE, GUMBEL | 50,257 | 135 µs | 3804 µs | 125.9 µs | 12,591 |
| SAMPLE, GUMBEL | 151,936 | 294 µs | 11572 µs | 380.1 µs | 38,010 |
| DETECT, per token | — | 4.3 ns | — | 5.0 ns | 0.50 |

The desktop core runs at several GHz and is shown as an upper bound on CPU software. The
PYNQ-Z2's Cortex-A9 at 650 MHz has not been measured; it would be several times slower than
the desktop figure.
