# Sampling distribution through the RTL

Generated by `python3 scripts/stats_rtl.py`. 20,000 SAMPLE commands per scheme through the
cycle-accurate simulation, every response also matched against the golden model. The
target distribution is computed from the int16 Q8.8 logits the IP actually receives.

| scheme | how the randomness varies | target | χ² (4 degrees of freedom) | p-value | responses equal to the golden model |
|---|---|---|---|---|---|
| GUMBEL | context = step index, 0 … 19999 | softmax(l) | 6.14 | 0.19 | all |
| GREEN, γ 0.4, δ 2.0 | fixed context, step 0 … 19999 | softmax(l + δ·green), green set [1, 0, 1, 0, 0] | 1.97 | 0.74 | all |

A p-value above 0.05 means the observed frequencies are consistent with the target.
